## Nguyên tắc

1. **Làm trước, xem đáp án sau.** Ghi câu trả lời ra giấy rồi mới mở file đáp án.
2. **Câu sai là dữ liệu.** Ghi lỗi vào [ERROR-LOG](../13-LEARNING-TRACKER/ERROR-LOG.md) và quay lại bài lý thuyết được liên kết trong đáp án.
3. **Không làm hết một lần.** Chia nhỏ để có câu chưa gặp dùng cho các buổi ôn sau.
4. **Chấp nhận nhiều đáp án.** Ở các bài viết lại, dịch và hội thoại, file đáp án nêu phương án tham khảo; câu khác vẫn đúng nếu đúng ngữ pháp và giữ nghĩa.
