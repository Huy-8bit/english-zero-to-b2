# LAB-09 · Weekly Review — Bộ ôn tập cuối tuần

| Mục | Nội dung |
|---|---|
| **Thời lượng** | 45–60 phút, mỗi tuần một lần |
| **Cách dùng** | Làm 5 trạm theo thứ tự. Trạm 1 làm **không mở sách**. Ghi kết quả vào [WEEKLY-REVIEW](../13-LEARNING-TRACKER/WEEKLY-REVIEW.md) và [PROGRESS](../13-LEARNING-TRACKER/PROGRESS.md). |
| **Gợi ý** | [LAB-09-GUIDE](../12-ANSWERS-AND-EXPLANATIONS/PRACTICE-LAB/LAB-09-GUIDE.md) |

> LAB-09 là **bài tập** để làm; [WEEKLY-REVIEW](../13-LEARNING-TRACKER/WEEKLY-REVIEW.md) là **nhật ký** ghi lại kết quả. Dùng cả hai.

## Trạm 1 — Nhớ lại (10 phút, không mở tài liệu)

1. Viết tên **tất cả** chủ điểm ngữ pháp đã học trong tuần.
2. Với mỗi chủ điểm: viết công thức + 2 câu ví dụ của riêng bạn (1 khẳng định, 1 phủ định hoặc nghi vấn).
3. Viết 10 từ/cụm từ mới học trong tuần và đặt câu với 5 từ.
4. Mở tài liệu, tự chấm. Đánh dấu ✗ phần nhớ sai → đưa vào [SPACED-REPETITION](../13-LEARNING-TRACKER/SPACED-REPETITION.md).

## Trạm 2 — Sửa lại lỗi cũ (10 phút)

1. Mở [ERROR-LOG](../13-LEARNING-TRACKER/ERROR-LOG.md), chọn 5 lỗi gần nhất.
2. Che cột "câu đúng", tự viết lại từng câu.
3. Với mỗi lỗi, viết **một câu mới** trong ngữ cảnh khác dùng đúng quy tắc.
4. Lỗi nào sai lần 2 → ghi chú "ưu tiên" cho tuần sau.

## Trạm 3 — Bài trộn (10 phút)

Chọn **một** bộ phù hợp cấp độ trong [LAB-01](LAB-01-daily-grammar-drills.md) hoặc 10 câu trong [LAB-02](LAB-02-mixed-grammar-exercises.md) mà bạn **chưa làm**. Tính điểm %.

## Trạm 4 — Sản xuất ngôn ngữ (15 phút)

| Kỹ năng | Nhiệm vụ |
|---|---|
| Nói (5 phút) | Ghi âm 1–2 phút về chủ đề: *What did I learn this week and how can I use it?* Dùng ít nhất 2 cấu trúc mới. |
| Viết (10 phút) | Viết 80–150 từ (tùy cấp) kể lại tuần của bạn. Gạch chân các cấu trúc mới đã dùng. |

## Trạm 5 — Lập kế hoạch (5 phút)

Điền vào khung kế hoạch trong [WEEKLY-REVIEW](../13-LEARNING-TRACKER/WEEKLY-REVIEW.md): 3 lỗi ưu tiên, bài học tiếp theo, buổi nghe/đọc, buổi nói/viết.

## Bảng điểm tuần

| Tuần | Trạm 1 (% nhớ đúng) | Trạm 2 (lỗi còn sai) | Trạm 3 (%) | Trạm 4 (cấu trúc mới đã dùng) | Ghi chú |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |

**Ngưỡng tham khảo:** Trạm 1 ≥ 70% và Trạm 3 ≥ 80% → học tiếp bài mới. Thấp hơn → dành thêm 1–2 buổi ôn bài cũ trước khi học tiếp.
