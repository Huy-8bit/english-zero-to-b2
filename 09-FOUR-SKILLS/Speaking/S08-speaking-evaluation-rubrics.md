# S08 · Speaking Evaluation Rubrics — Tự đánh giá kỹ năng nói

| Mục | Nội dung |
|---|---|
| **Cấp độ** | A1 → B2 |
| **Mục tiêu** | Tự chấm bài nói theo tiêu chí rõ ràng; xác định điểm yếu cụ thể để luyện |
| **Rubric chung** | [Skill Evaluation Rubrics](../../11-EXAMS-AND-ASSESSMENTS/SKILL-EVALUATION-RUBRICS.md) |

> Rubric do giáo trình biên soạn, **không** phải thang chấm chính thức của kỳ thi nào.

## 1. Năm tiêu chí

| Tiêu chí | Câu hỏi tự kiểm tra |
|---|---|
| **Độ trôi chảy & mạch lạc** | Tôi có nói liên tục không? Ý có theo trình tự logic không? Có từ nối không? |
| **Từ vựng** | Từ có phù hợp chủ đề không? Có lặp từ nhiều không? Có collocation tự nhiên không? |
| **Ngữ pháp** | Có lỗi thì, -s, mạo từ? Có dùng câu phức không? |
| **Phát âm** | Âm cuối, trọng âm từ, ngữ điệu — người nghe có hiểu dễ không? |
| **Hoàn thành nhiệm vụ / tương tác** | Có trả lời đúng câu hỏi? Có lý do, ví dụ? Có phản hồi câu hỏi tiếp nối? |

## 2. Thang mô tả theo cấp (tham khảo nội bộ)

| | A2 | B1 | B2 |
|---|---|---|---|
| **Trôi chảy** | Câu ngắn, nhiều ngập ngừng nhưng truyền đạt được ý đơn giản | Nói liên tục được về chủ đề quen thuộc, đôi khi ngập ngừng để tìm từ | Nói trôi chảy về nhiều chủ đề, ít ngập ngừng, tự sửa lỗi |
| **Mạch lạc** | Nối ý bằng *and, but, because* | Dùng từ nối đa dạng, kể chuyện có trình tự | Lập luận rõ ràng, dùng discourse markers tự nhiên |
| **Từ vựng** | Từ cơ bản về chủ đề hằng ngày | Đủ để nói về trải nghiệm, ý kiến; đôi khi phải paraphrase | Đa dạng, có collocation, diễn đạt ý trừu tượng |
| **Ngữ pháp** | Cấu trúc đơn giản, lỗi cơ bản thường xuyên | Kết hợp câu đơn và phức; lỗi không cản trở hiểu | Đa dạng cấu trúc, lỗi ít |
| **Phát âm** | Hiểu được với nỗ lực; giọng Việt rõ | Nhìn chung dễ hiểu; lỗi âm cuối/trọng âm | Rõ ràng, trọng âm và ngữ điệu hợp lý |

## 3. Quy trình tự chấm

1. **Ghi âm** bài nói (điện thoại là đủ).
2. **Nghe lần 1** — chỉ đánh giá trôi chảy và nội dung. Đếm số lần dừng > 3 giây.
3. **Viết lại** (transcribe) bài nói của mình — rất hiệu quả để thấy lỗi ngữ pháp.
4. **Nghe lần 2** — đánh dấu lỗi phát âm.
5. **Chấm 0–4** mỗi tiêu chí theo [Skill Evaluation Rubrics](../../11-EXAMS-AND-ASSESSMENTS/SKILL-EVALUATION-RUBRICS.md).
6. **Chọn 1 điểm cần cải thiện**, ghi vào [Error Log](../../13-LEARNING-TRACKER/ERROR-LOG.md).
7. **Nói lại** cùng chủ đề sau khi sửa.

## 4. Bảng phân loại lỗi khi nghe lại

| Loại lỗi | Ví dụ bạn nghe thấy | Số lần |
|---|---|---|
| Thiếu -s / -ed | *He go..., Yesterday I work...* | |
| Sai thì | | |
| Thiếu mạo từ | *She is teacher* | |
| Thiếu âm cuối | | |
| Sai trọng âm | | |
| Từ tiếng Việt chen vào / *ờ, à* quá nhiều | | |
| Câu trả lời quá ngắn | | |

## 5. Khi có người hỗ trợ chấm

- Đưa cho họ rubric và câu hỏi.
- Nhờ họ ghi **một điểm mạnh** và **một điểm cần cải thiện** cụ thể (không chỉ "nói tốt").
- Nếu dùng AI để nhận xét, đưa transcript bài nói + rubric và yêu cầu chỉ ra lỗi kèm ví dụ; xem [AI Tutor Instructions](../../AI-TUTOR-INSTRUCTIONS.md). Lưu ý AI không nghe được phát âm từ transcript.

## 6. Bài luyện

**1.** Ghi âm câu trả lời Part 3 ở [S07](S07-vstep-speaking.md) bài 4. Tự chấm theo quy trình 7 bước, điền bảng phân loại lỗi.
**2.** Sau 2 tuần, nói lại cùng đề và so sánh điểm.
