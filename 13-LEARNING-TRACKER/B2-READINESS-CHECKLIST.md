# B2 Readiness Checklist — Danh sách kiểm tra sẵn sàng B2

[Trang theo dõi](README.md) · [B2 Mock Test 1](../11-EXAMS-AND-ASSESSMENTS/B2-MOCK-TEST-1.md) · [B2 Mock Test 2](../11-EXAMS-AND-ASSESSMENTS/B2-MOCK-TEST-2.md) · [VSTEP-style Mock Exam 1 (mô phỏng)](../11-EXAMS-AND-ASSESSMENTS/VSTEP-STYLE-MOCK-EXAM-1.md)

Danh sách này giúp bạn tự kiểm tra xem mình đã có các khả năng thường được mô tả ở trình độ B2 (theo tinh thần khung CEFR) hay chưa. **Đây là công cụ tự đánh giá, không thay thế bài thi chính thức.** Các đề mô phỏng trong dự án không phải đề thi VSTEP chính thức và không cho ra điểm/chứng chỉ chính thức.

Đánh dấu một mục chỉ khi bạn có **bằng chứng**: bản ghi âm, bài viết đã chấm theo rubric, hoặc kết quả bài kiểm tra.

## 1. Listening — Nghe

| Tôi có thể... | Bằng chứng | ✓ |
|---|---|---|
| Hiểu ý chính và chi tiết của bài nói dài về chủ đề quen thuộc ở tốc độ tự nhiên | Bài nghe B2 trong [B2 Skills Practice](../05-B2-UPPER-INTERMEDIATE/B2-SKILLS-PRACTICE.md) | |
| Theo dõi lập luận trong bài thuyết trình, nhận ra quan điểm và thái độ người nói | | |
| Hiểu phần lớn tin tức và phóng sự trên radio/TV | | |
| Nghe hiểu hội thoại giữa người bản ngữ khi chủ đề quen thuộc | | |
| Đạt mốc gợi ý phần Listening ở cả hai B2 Mock Test | | |

## 2. Reading — Đọc

| Tôi có thể... | Bằng chứng | ✓ |
|---|---|---|
| Đọc bài báo, bài viết về vấn đề xã hội và hiểu quan điểm tác giả | | |
| Đọc lướt nhanh văn bản dài để tìm thông tin cần thiết | [R02](../09-FOUR-SKILLS/Reading/R02-skimming.md) | |
| Suy luận nghĩa từ mới từ ngữ cảnh | | |
| Phân biệt sự thật và ý kiến; nhận ra giọng điệu | | |
| Đạt mốc gợi ý phần Reading ở cả hai B2 Mock Test | | |

## 3. Speaking — Nói

| Tôi có thể... | Bằng chứng | ✓ |
|---|---|---|
| Nói liên tục 2 phút về một chủ đề với ít lần dừng dài | Bản ghi [LAB-07](../10-PRACTICE-LAB/LAB-07-speaking-challenges.md) | |
| Trình bày quan điểm, đưa lý do và ví dụ, phản hồi ý kiến trái chiều | | |
| Tham gia thảo luận, đồng ý/phản đối lịch sự, đề xuất giải pháp | | |
| Phát âm rõ, trọng âm và ngữ điệu tự nhiên đủ để người nghe không phải cố gắng | | |
| Đạt mức B2 ở các tiêu chí của [S08](../09-FOUR-SKILLS/Speaking/S08-speaking-evaluation-rubrics.md) | | |

## 5. Grammar & Vocabulary — Ngữ pháp và từ vựng

| Tôi có thể... | Bằng chứng | ✓ |
|---|---|---|
| Dùng chính xác tất cả các thì và câu điều kiện (kể cả hỗn hợp) | [ALL-CONDITIONALS](../06-GRAMMAR-REFERENCE/ALL-CONDITIONALS.md) | |
| Dùng bị động, câu tường thuật, mệnh đề quan hệ linh hoạt | | |

| Phần lớn bài B1–B2 trong [Grammar Checklist](GRAMMAR-CHECKLIST.md) có dấu "Dùng độc lập" | | |

## 6. Kết luận

| Số mục đã có bằng chứng | Gợi ý |
|---|---|
| < 15 | Tiếp tục học B2; tập trung vào kỹ năng có ít dấu nhất |
| 15–22 | Gần sẵn sàng; luyện thêm bằng [VSTEP-style Mock Exam 2 (mô phỏng)](../11-EXAMS-AND-ASSESSMENTS/VSTEP-STYLE-MOCK-EXAM-2.md) và sửa lỗi lặp lại |
| 23–26 | Khả năng cao đã ở mức B2 trong các kỹ năng đã kiểm tra. Nếu cần chứng nhận, đăng ký kỳ thi chính thức tại đơn vị tổ chức được cấp phép |

> Ghi lại ngày hoàn thành từng mục. Nếu sau 1–2 tháng không còn dùng được một khả năng, bỏ dấu và ôn lại.
