| Collocation | Nghĩa | Ví dụ |
|---|---|---|
| **read / watch / follow** the news | đọc / xem / theo dõi tin | |
| **make (the) headlines** | lên trang nhất | *The story **made headlines** worldwide.* |
| **break** the news | báo tin | |
| **breaking news** | tin nóng | |
| **go viral** | lan truyền | |
| **spread** fake news / rumours | lan truyền tin giả | |
| **a reliable / trustworthy** source | nguồn đáng tin | |
| **fact-check** a story | kiểm chứng | |

| **public opinion** | dư luận | |

## 3. Lỗi thường gặp

| ❌ | ✅ | Giải thích |
|---|---|---|
| *The news **are** good.* | *The news **is** good.* | *news* số ít |
| *a news* | *a piece of news / a news story* | Không đếm được |
| *I read it on **the** newspaper.* | *I read it **in** the newspaper.* | Giới từ |
| *I saw it **in** TV.* | *I saw it **on** TV.* | |
| *He is a famous **journalism**.* | *He is a famous **journalist**.* | Danh từ chỉ người |
| *The report is **bias**.* | *The report is **biased**.* | Tính từ |

### A. Chọn từ đúng

**1.** The news ___ shocking yesterday.  A. were  B. was  C. are
**2.** I saw the interview ___ TV.  A. in  B. on  C. at
**3.** False information spread on purpose is called ___.  A. misinformation  B. disinformation  C. coverage
**4.** This newspaper always supports one party — it's very ___.  A. biased  B. bias  C. viral
**5.** "You won't believe what happened next!" is a typical example of ___.  A. documentary  B. clickbait  C. censorship

### B. Điền từ: *verify, source, influencers, coverage, made headlines*

**6.** Always ___ a story before sharing it.
**7.** The scandal ___ around the world.
**8.** Many brands pay ___ to promote their products.
**9.** The election received huge media ___.
**10.** Is Wikipedia a reliable ___?

### C. Sửa lỗi

**13.** That journalist's report is bias.
