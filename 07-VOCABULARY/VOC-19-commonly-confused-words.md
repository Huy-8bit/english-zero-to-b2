# VOC-19 · Commonly Confused Words — Từ dễ nhầm lẫn

| Mục | Nội dung |
|---|---|
| **Cấp độ** | A2 → B2 |
| **Số mục** | 40 cặp/nhóm từ |
| **Thời gian gợi ý** | 3 buổi × 30 phút |

> Các cặp từ dưới đây bị nhầm vì **giống nghĩa trong tiếng Việt**, **giống cách viết**, hoặc **giống phát âm**. Mỗi cặp có ví dụ ngắn; tự đặt thêm một câu cho mỗi từ để nhớ lâu.

## 1. Nghĩa gần nhau (dịch tiếng Việt giống nhau)

| Cặp | Phân biệt | Ví dụ |
|---|---|---|
| **borrow / lend** | mượn (nhận về) / cho mượn (đưa đi) | *Can I **borrow** your pen? / Can you **lend** me your pen?* |
| **say / tell** | *say* + điều được nói / *tell* + người | *She **said** hello. / She **told** me a story.* |
| **speak / talk** | *speak* trang trọng hơn, ngôn ngữ / *talk* trò chuyện | *I **speak** English. / We **talked** for hours.* |
| **look / see / watch** | nhìn có chủ ý / thấy / xem (vật chuyển động, lâu) | ***Look** at this! I **saw** him. I **watch** TV.* |
| **hear / listen** | nghe thấy / lắng nghe | *I **heard** a noise. **Listen** to me!* |
| **make / do** | tạo ra / thực hiện công việc | *[VOC-17](VOC-17-common-collocations.md)* |
| **bring / take** | mang đến (về phía người nói) / mang đi | ***Bring** it here. **Take** it to her.* |
| **remember / remind** | nhớ / nhắc | *I **remember** her. **Remind** me to call her.* |
| **forget / leave** | quên (không nói nơi) / để quên ở đâu | *I **forgot** my keys. I **left** my keys at home.* |
| **win / beat** | thắng (cuộc thi, giải) / đánh bại (người) | *We **won** the match. We **beat** them 2–0.* |
| **rob / steal** | cướp (người, nơi) / lấy cắp (đồ) | *They **robbed** a bank. They **stole** $1m.* |
| **job / work** | công việc (đếm được) / công việc (không đếm được) | *a new **job** / a lot of **work*** |
| **travel / trip / journey** | đi lại (chung) / chuyến đi / hành trình (quãng đường) | *I love **travel**. A **trip** to Hue. A long **journey**.* |
| **trip / tour** | chuyến đi / chuyến tham quan có hướng dẫn | *a business **trip** / a guided **tour*** |
| **fun / funny** | vui (thú vị) / buồn cười | *The party was **fun**. The joke was **funny**.* |
| **wish / hope** | ước (khó/không có thật) / hy vọng (có thể xảy ra) | *I **wish** I were taller. I **hope** you pass.* |

## 2. Giống nhau về hình thức

| Cặp | Phân biệt | Ví dụ |
|---|---|---|
| **affect / effect** | động từ / danh từ | *Stress **affects** sleep. Stress has an **effect** on sleep.* |
| **rise / raise** | nội động từ (tự tăng) / ngoại động từ (làm tăng) | *Prices **rose**. They **raised** prices.* |
| **lie / lay** | nằm (lie–lay–lain) / đặt (lay–laid–laid) | *I **lay** down. She **laid** the book on the table.* |
| **sensible / sensitive** | hợp lý / nhạy cảm | *a **sensible** decision / **sensitive** skin* |
| **economic / economical** | kinh tế / tiết kiệm | *economic growth / an economical car* |
| **historic / historical** | có ý nghĩa lịch sử / thuộc về lịch sử | |
| **moral / morale** | đạo đức, bài học / tinh thần | *the **moral** of the story / team **morale*** |
| **lose / loose** | mất, thua / lỏng | *Don't **lose** it. These jeans are **loose**.* |
| **quiet / quite** | yên lặng / khá | *Be **quiet**. It's **quite** good.* |
| **advice / advise** | danh từ / động từ | *good **advice** / I **advise** you to go.* |
| **practice / practise** | danh từ / động từ (Anh–Anh) | *more **practice** / **practise** every day* |
| **cook / cooker** | đầu bếp / cái bếp | *He's a good **cook**. A gas **cooker**.* |
| **alone / lonely** | một mình / cô đơn | *I live **alone** but I'm not **lonely**.* |
| **especially / specially** | đặc biệt là / dành riêng | ***especially** in summer / made **specially** for you* |
| **beside / besides** | bên cạnh / ngoài ra | |
| **among / between** | giữa (3+) / giữa (2, hoặc các đối tượng riêng biệt) | |

## 3. Từ gần giống trong ngữ pháp

| Cặp | Phân biệt |
|---|---|
| **few / a few; little / a little** | ít (tiêu cực) / một vài (tích cực) — [A2-G024](../03-A2-ELEMENTARY/grammar/A2-G024-quantifiers.md) |
| **fewer / less** | đếm được / không đếm được |
| **since / for** | mốc / khoảng thời gian |
| **during / while** | + danh từ / + mệnh đề |
| **because / because of** | + mệnh đề / + danh từ |
| **although / despite** | + mệnh đề / + danh từ, V-ing |
| **used to / be used to** | thói quen cũ / quen với |
| **its / it's** | của nó / it is |
| **your / you're**, **their / there / they're** | sở hữu / viết tắt / trạng từ |

## 4. Giống phát âm (homophones)

| Từ | IPA | Ví dụ |
|---|---|---|
| **weather / whether** | /ˈweðə/ | *the **weather** / I don't know **whether** to go.* |
| **peace / piece** | /piːs/ | *world **peace** / a **piece** of cake* |
| **right / write** | /raɪt/ | |
| **hear / here** | /hɪə/ | |
| **whole / hole** | /həʊl/ | |
| **advice** /ədˈvaɪs/ vs **advise** /ədˈvaɪz/ | khác âm cuối /s/–/z/ | |
| **desert** /ˈdezət/ (sa mạc) vs **dessert** /dɪˈzɜːt/ (tráng miệng) | khác trọng âm | |

**5.** Lack of sleep can ___ your concentration.  A. affect  B. effect
**6.** The company ___ its prices last month.  A. rose  B. raised
**7.** Please be ___ — the baby is sleeping.  A. quiet  B. quite
**8.** He lives ___, but he never feels lonely.  A. alone  B. lonely
**9.** Can I give you some ___?  A. advice  B. advise
**10.** The party was really ___.  A. fun  B. funny
**11.** I ___ I could speak Japanese.  A. hope  B. wish
**12.** Three men ___ a jewellery shop yesterday.  A. stole  B. robbed
