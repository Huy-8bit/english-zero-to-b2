## 2. Collocations

| Collocation | Nghĩa | Ví dụ |
|---|---|---|
| **tackle / address** a problem | giải quyết vấn đề | |
| **reduce** poverty / inequality | giảm nghèo / bất bình đẳng | |
| **commit** a crime | phạm tội | |
| **break / obey** the law | vi phạm / tuân thủ luật | |
| **introduce / implement** a policy | ban hành / thực thi chính sách | |
| **raise / pay** taxes | tăng / nộp thuế | |
| **do** voluntary / charity work | làm tình nguyện / từ thiện | |
| **have access to** | có quyền tiếp cận | *Everyone should **have access to** healthcare.* |
| **social issues / problems** | vấn đề xã hội | |
| **equal opportunities** | cơ hội bình đẳng | |
| **play a role in** | đóng vai trò | |
| **the gap between rich and poor** | khoảng cách giàu nghèo | |
| **a sense of community** | tinh thần cộng đồng | |
| **give back to** the community | đóng góp lại cho cộng đồng | |

## 3. Lỗi thường gặp

| ❌ | ✅ | Giải thích |
|---|---|---|
| *The **old people** are lonely.* (nói chung, trang trọng) | ***The elderly / older people** are often lonely.* | Lịch sự hơn |
| *Population of Vietnam **are** large.* | ***The** population of Vietnam **is** large.* | Mạo từ, hòa hợp |
| *He **made** a crime.* | *He **committed** a crime.* | |
| *Government should...* | ***The** government should...* | Mạo từ |
| *Rich people **and** poor people gap* | *the gap **between** rich **and** poor* | |
| *Everyone has right to education.* | *Everyone has **the** right to education.* | |

## 4. Bài tập

> ✍️ Đáp án: [VOC-10-ANSWERS](../12-ANSWERS-AND-EXPLANATIONS/VOCABULARY/VOC-10-ANSWERS.md)

### A. Chọn từ đúng

**1.** He was arrested for ___ a crime.  A. making  B. committing  C. doing
**2.** The movement of people from rural areas to cities is called ___.  A. migration  B. inequality  C. welfare
**3.** In many countries, the number of older people is rising — this is an ___ population.  A. elderly  B. ageing  C. old
**4.** Treating people unfairly because of their gender is ___.  A. discrimination  B. equality  C. charity
**5.** The government plans to ___ a new housing policy.  A. implement  B. commit  C. obey

### B. Điền từ: *standard of living, affordable housing, stereotypes, have access to, breadwinner*

**6.** Young couples in big cities struggle to find ___.
**7.** All children should ___ quality education.
**8.** The ___ in Vietnam has improved significantly over the past 30 years.
**9.** Gender ___ suggest that only men should be engineers.
**10.** After her husband lost his job, she became the family's ___.

### C. Sửa lỗi

**11.** Government should reduce the gap rich and poor.
**12.** Population of the city are growing quickly.
**13.** Everyone has right to healthcare.
