# PRON-07 · Linking Sounds — Nối âm

| Mục | Nội dung |
|---|---|
| **Cấp độ** | A2 → B2 |
| **Mục tiêu** | Nối âm giữa các từ để nói trôi chảy; nghe ra các cụm từ bị nối |
| **Liên quan** | [PRON-06 Connected speech](PRON-06-connected-speech.md) |

Người Việt thường đọc từng từ tách rời (do mỗi âm tiết tiếng Việt độc lập), khiến câu nghe "gãy". Nối âm giúp câu **liền mạch** và giúp bạn **nghe hiểu** người bản ngữ.

Ký hiệu trong bài: **‿** = nối.

## 1. Phụ âm + Nguyên âm (C + V)

Phụ âm cuối của từ trước **chuyển sang** đầu từ sau.

| Viết | Nghe như | |
|---|---|---|
| *turn‿off* | tur-noff | /tɜː nɒf/ |
| *pick‿it‿up* | pi-ki-tup | |
| *an‿apple* | a-napple | |
| *look‿at* | loo-kat | |
| *get‿out* | ge-tout | |
| *find‿out* | fin-dout | |
| *not‿at‿all* | no-ta-tall | |
| *as‿soon‿as* | a-ssoo-nas | |

## 2. Nguyên âm + Nguyên âm (V + V): thêm /w/ hoặc /j/

Khi một từ kết thúc bằng nguyên âm và từ sau bắt đầu bằng nguyên âm, người nói thường chèn một âm lướt nhẹ:

| Âm cuối | Chèn | Ví dụ |
|---|---|---|
| /uː/, /əʊ/, /aʊ/ (tròn môi) | /w/ | *do‿(w)it, go‿(w)away, how‿(w)are you, too‿(w)expensive* |
| /iː/, /eɪ/, /aɪ/, /ɔɪ/ | /j/ | *I‿(j)am, the‿(j)end, say‿(j)it, be‿(j)able, my‿(j)uncle* |

## 3. Linking /r/ (Anh–Anh)

Trong giọng Anh–Anh, /r/ cuối từ **không đọc**, trừ khi từ sau bắt đầu bằng **nguyên âm**:

| Đứng một mình | Nối |
|---|---|
| *car* /kɑː/ | *car‿(r)is* /kɑːr ɪz/ |
| *far* /fɑː/ | *far‿(r)away* |
| *here* /hɪə/ | *here‿(r)it is* |
| *mother* /ˈmʌðə/ | *mother‿(r)and father* |

(Giọng Mỹ luôn đọc /r/, nên nối tự nhiên.)

## 4. Phụ âm + Phụ âm giống nhau

Khi hai phụ âm giống nhau (hoặc gần giống) gặp nhau, chỉ đọc **một lần, giữ lâu hơn một chút**:

| Viết | Nghe |
|---|---|
| *bus‿stop* | bu-stop |
| *big‿girl* | bi-girl |
| *black‿cat* | bla-cat |
| *with‿this* | wi-this |
| *good‿day* | goo-day |

## 5. Nối với *the* và *a/an*

- *the* + phụ âm: /ðə/ — *the book*; *the* + nguyên âm: thường /ði/ — *the‿(j)apple* (cả hai cách đều được chấp nhận trong lời nói hiện đại).
- *an* luôn nối: *an‿hour* /ə naʊə/.

## 6. Luyện tập theo câu

| Câu | Có nối |
|---|---|
| *Can I have an apple?* | *Can‿I‿have‿an‿apple?* |
| *Pick it up and put it on.* | *Pick‿it‿up‿and put‿it‿on.* |
| *I'll be there in an hour.* | *I'll be there‿(r)in‿an‿hour.* |
| *Go away!* | *Go‿(w)away!* |
