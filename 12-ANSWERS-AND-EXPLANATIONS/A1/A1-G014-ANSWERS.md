# A1-G014 · Answer Key — Some / Any

> Bài học: [A1-G014](../../02-A1-BEGINNER/grammar/A1-G014-some-any.md)

## Level 1 — Recognition

| Câu | Đáp án | Giải thích |
|---|---|---|
| L1.1 | **A. some** | Khẳng định + số nhiều. |
| L1.2 | **B. any** | Phủ định (*don't*). C sai vì phủ định kép. |
| L1.3 | **B. some** | Lời mời. |
| L1.4 | **A. anybody** | Câu hỏi trung tính. |
| L1.5 | **C. no** | Động từ khẳng định (*There's*) + nghĩa "không còn" → *no*. |
| L1.6 | **A** | *something + adj + to V*. |

## Level 2 — Controlled Practice

| Câu | Đáp án | Giải thích |
|---|---|---|
| L2.1 | **some** | Yêu cầu |
| L2.2 | **any** | Phủ định |
| L2.3 | **any** | Câu hỏi trung tính (*some* cũng chấp nhận nếu đây là lời đề nghị giúp đỡ: *Do you need some help?* — người nói nghĩ bạn cần giúp) |
| L2.4 | **some** | Khẳng định; *news* không đếm được |
| L2.5 | **no** | *are* khẳng định + nhấn mạnh |
| L2.6 | **any** | "bất kỳ" |
| L2.7 | **anything** | Câu hỏi |
| L2.8 | **Someone** (*Somebody*) | Khẳng định |
| L2.9 | **anywhere** | *couldn't* — phủ định |
| L2.10 | **Nothing** | "Không có gì." |

## Level 3 — Error Correction

| Câu | Sửa |
|---|---|
| L3.1 | I don't have **any** friends in this city. |
| L3.2 | Would you like **some** coffee? |
| L3.3 | There isn't **any** sugar. / There **is no** sugar. |
| L3.4 | Somebody **is** waiting for you. |
| L3.5 | Do you have **any** questions? |
| L3.6 | I want to buy **something interesting** for my mum. |

## Level 4 — Production

| Câu | Đáp án |
|---|---|
| L4.1 | There aren't **any** chairs in the room. / There are **no** chairs in the room. |
| L4.2 | Would you like **something** to eat? |
| L4.3 | I don't know **anyone** at the party. |
| L4.4 | Can I have **some** sugar, please? |
| L4.5 | **Nobody** is at home. / There's **nobody** at home. |

## Level 5 — Real Communication

**L5.1.** Mẫu:

> **A:** Let's make omelettes for breakfast. Are there any eggs?
> **B:** Yes, there are some eggs, but there isn't any cheese.
> **A:** That's OK. Do we have any tomatoes?
> **B:** No, we have no tomatoes. But there are some onions.
> **A:** Great. Is there anything to drink?
> **B:** There's some orange juice. Would you like some?
> **A:** Yes, please. Oh, is anyone else coming?
> **B:** No, nobody. Just us!

✅ Tiêu chí: *some* (khẳng định/mời), *any* (hỏi/phủ định), *no* + V khẳng định; ≥ 2 từ ghép (*anything, anyone, nobody*).

**L5.2.** Mẫu:
- *Are there any good restaurants nearby? — Yes, there are some great seafood restaurants on the beach.*
- *Is there anything interesting to see? — Yes, there's an old temple and some nice markets.*
- *Is there anywhere I can rent a motorbike? — Yes, you can rent one at the shop next to the hotel.*
- *Is there anyone who speaks English at the tour office? — Yes, someone there speaks English very well.*
- *Do you have any maps? — Yes, we have some free maps here.*
