# PRON-07 · Answer Key — Linking Sounds

| Câu | Đáp án | Ghi chú |
|---|---|---|
| 1 | I need‿a cup‿of tea. | C+V |
| 2 | Turn‿it‿off, please. | C+V |
| 3 | She lives‿in‿an‿old house. | C+V |
| 4 | Can you look‿after‿(r)it? | C+V; linking /r/ (Anh–Anh) |
| 5 | We stayed‿at‿a hotel. | C+V |
| 6 | **/w/** — *go‿(w)out* | |
| 7 | **/j/** — *I‿(j)agree* | |
| 8 | **/r/** — *far‿(r)away* | |
| 9 | **/w/** — *two‿(w)apples* | |
| 10 | **/j/** — *the‿(j)end* (khi đọc *the* là /ði/) | |

> Có thể có thêm chỗ nối nhẹ khác (ví dụ *cup‿of* thường nghe như "cu-pəv"). Chấp nhận nếu hợp lý.
