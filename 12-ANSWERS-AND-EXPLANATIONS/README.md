# 12 · Answers and Explanations — Đáp án và lời giải

Đáp án được tách riêng khỏi bài học để bạn **làm bài trước, kiểm tra sau**. Mỗi file đáp án có link quay lại bài gốc.

## Cách dùng đáp án hiệu quả

1. Làm hết một Level (hoặc một phần) rồi mới mở đáp án; không kiểm tra từng câu.
2. Với câu sai, đọc **giải thích** chứ không chỉ chép đáp án đúng.
3. Ở bài viết và nói, đọc **rubric** và tự chấm bản của bạn trước khi xem bài mẫu. Bài mẫu chỉ là một phương án.
4. Ghi lỗi lặp lại vào [ERROR-LOG](../13-LEARNING-TRACKER/ERROR-LOG.md).

## Quy ước trong file đáp án

| Ký hiệu | Ý nghĩa |
|---|---|
| `L1.1`, `L2.3`… | Mã câu theo Level trong bài học |
| **in đậm** | Đáp án chính |
| *A / B* | Các phương án đều chấp nhận |
| ~~gạch ngang~~ | Dạng sai thường gặp |
| Knowledge Check | Câu hỏi tự kiểm tra cuối mỗi file đáp án bài học |

> **Transcript và audio:** Dự án không kèm file âm thanh. Các file `*-LISTENING-TRANSCRIPTS.md` có lời thoại đầy đủ để bạn đọc to cho bạn học nghe hoặc dùng công cụ chuyển văn bản thành giọng nói (TTS); xem hướng dẫn trong [09-FOUR-SKILLS/Listening](../09-FOUR-SKILLS/Listening/README.md).
