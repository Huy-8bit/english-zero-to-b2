## Học trên web

Thư mục [platform/](platform/README.md) chứa ứng dụng web học tương tác dùng chính giáo trình này: học từng slide, bài tập được chấm, lưu tiến độ, flashcards, tìm kiếm. Chạy: `cd platform && scripts/setup.sh && scripts/dev.sh`.

## Trạng thái dự án

**Đủ nội dung theo bản đồ:** 128/128 bài ngữ pháp A0→B2 kèm đáp án, cùng tra cứu ngữ pháp, từ vựng, phát âm, 38 chương bốn kỹ năng, Practice Lab, đề kiểm tra cuối cấp, B2 mock test và tracker. Cả 128 cặp bài–đáp án đã được tác giả đọc đối chiếu (chưa có giáo viên độc lập thẩm định). Kiểm tra tự động: 0 liên kết nội bộ hỏng.

- [IMPLEMENTATION-STATUS.md](IMPLEMENTATION-STATUS.md) — những gì đã hoàn thành và đang thực hiện.
- [CONTENT-AUDIT.md](CONTENT-AUDIT.md) — báo cáo kiểm định, gồm trạng thái từng bài và kết quả kiểm tra tự động.
- [AI-TUTOR-INSTRUCTIONS.md](AI-TUTOR-INSTRUCTIONS.md) — cách luyện cùng AI mà không bỏ qua tiên quyết hoặc xem đáp án trước.

## Lưu ý

- Toàn bộ tài liệu là Markdown (UTF-8), đọc tốt trên **VS Code Markdown Preview**, **GitHub** và **Obsidian**. Sơ đồ dùng Mermaid (VS Code cần extension hỗ trợ Mermaid, ví dụ *Markdown Preview Mermaid Support*).
- Bộ tài liệu **không kèm file âm thanh**. Phần nghe được thiết kế với transcript và hướng dẫn tự tạo audio bằng công cụ chuyển văn bản thành giọng nói (TTS) — xem [Listening README](09-FOUR-SKILLS/Listening/README.md).
- Các đề "VSTEP-style" là **bài luyện tập mô phỏng tự biên soạn**, không phải đề thi chính thức.
